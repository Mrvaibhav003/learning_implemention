Que.3) Write a PHP program to check whether a given number is prime or 
not
<?php
$num = 2;
$count = 0;
for ($i = 1; $i <= $num; $i++)
{
if ($num % $i == 0)
{
$count++;
}
}
if ($count == 2)
{
echo "Number Is Prime";
}
else
{
echo "Number Is Not Prime";
}
?>
